# Quickstart Validation Guide: Migrate SSH Settings from Deprecated MatchBlocks

**Branch**: `009-migrate-ssh-settings` | **Date**: 2026-10-12 | **Spec**: [spec.md](spec.md)

This guide provides step-by-step procedures to validate that the SSH configuration migration completely eliminates evaluation warnings, preserves SSH host directives, and satisfies all quality gates.

---

## Prerequisites

1. Working copy of `my-nixos-configurations` on branch `009-migrate-ssh-settings`.
2. Nix with Flakes enabled (`nix-command flakes`).
3. `just` task runner installed.

---

## Scenario 1: Verify Elimination of Evaluation Warnings

Verify that flake evaluation across all hosts completes cleanly without deprecation warnings regarding `programs.ssh.matchBlocks`.

```bash
# 1. Evaluate desktop-pc system derivation
nix eval .#nixosConfigurations.desktop-pc.config.system.build.toplevel.drvPath

# 2. Evaluate homelab system derivation
nix eval .#nixosConfigurations.homelab.config.system.build.toplevel.drvPath
```

**Expected Outcome**:

- Both commands output valid `.drv` paths.
- Stderr contains **zero** warnings regarding `programs.ssh.matchBlocks` or `programs.ssh.settings`.

---

## Scenario 2: Verify Generated SSH Client Configuration Parity

Inspect the rendered `~/.ssh/config` file generated by Home Manager to verify directive equivalence for all configured hosts.

```bash
# Query the evaluated .ssh/config text
nix eval --raw .#nixosConfigurations.desktop-pc.config.home-manager.users.laurent.home.file.".ssh/config".text
```

**Expected Outcome**:

- Output contains the blocks:

  ```text
  Host homelab
    CheckHostIP no
    HostName 192.168.1.180
    IdentityFile ~/.ssh/id_ed25519
    User laurent
  ```

- The target hostname, user, identity file, and security options match the intended configuration.

---

## Scenario 3: Verify Formatting & Static Analysis

Ensure that `modules/services/ssh.nix` adheres to code hygiene rules without dead code or syntax errors.

```bash
# 1. Format Nix expressions with alejandra
just fmt

# 2. Run static analysis (statix) and dead code detection (deadnix)
just lint
```

**Expected Outcome**:

- `just fmt` passes cleanly with no formatting diff.
- `just lint` completes with exit code 0 and zero warnings.

---

## Scenario 4: Hermetic Pre-Commit Checks

Run hermetic sandbox checks across all targets to guarantee flake integrity.

```bash
# Run all pre-commit checks and flake validations
just check
```

**Expected Outcome**:

- All git-hooks checks pass with exit code 0.
